# 最终实验的数据、方法、预期结果与图表说明

本文档说明论文最终保留的 RQ1—RQ3。

## 1. 比较范围与运行入口

主实验在固定任务规则下比较 **All-known 与 Human-only**。

- **All-known（全账号）**：纳入账号类型已解析的参与记录，包括人类、机器人和 AI 代理账号。
- **Human-only（仅人类）**：按具体任务保留人类执行账号或人类审阅人候选。
- 报告时将机器人和服务账号标签合并为机器人。PR 层 AI 工具标记记录工具类别，作者账号身份依据账号类型标签确定。
- 将已有数据集及派生账号标签视为工作假设。

安装文档要求的依赖后，从仓库根目录运行主入口：

```sh
python scripts/build_role_aware_network.py --events data/processed/actor_pr_events.parquet --actor-labels data/processed/actor_labels.parquet --out outputs/role_aware_network
python scripts/run_rq1.py
python scripts/run_rq2.py
python scripts/run_rq3.py
python scripts/check_results.py --result-dir outputs
```

构图命令先准备 RQ1 的输入，三条 `run_rq*.py` 命令分别向 `outputs/rq1`、`outputs/rq2` 和 `outputs/rq3` 写入结果。核验程序将新生成的主结果与文档中的参考数值比较。依赖安装、可用参数、资源估计及当前运行状态以仓库 README 为准。

主入口仅计算终稿报告的两种账号范围。

## 3. RQ1：账号范围与社区归属

### 问题与输入筛选

纳入非人类账号后，**两图共同的人类账号**被判为同一协作小组的关系是否变化？

使用完整所选事件快照。保留 PR 创建（`author`）、正式审阅（`review`）、行级审阅评论（`review_comment`）和普通评论（`comment`）；排除 commit、时间线、指派和合成工具标签关系。

分别在两种范围内确定活跃账号：账号至少参与一次由不同账号形成的作者—审阅人或作者—评论者关系，才满足该范围内的活跃条件。用保留的活跃账号构造无向账号—PR 二部图。每条所选记录使对应账号—PR 边权加一，多条事件按原始次数累加。

账号与 PR 节点均参与社区划分；分区一致性仅在两张完整图共同的人类账号上计算。活跃条件在各账号范围内分别计算，人类账号及 PR 的保留范围随交互关系筛选而变化。

### 算法、随机种子与指标

- 算法：Leiden 的 `ModularityVertexPartition`，普通加权模块度及默认设置。
- 随机种子：`0, 1, 2, 3, 4, 42, 123, 2024`。
- 保留按稳定标识排序的节点顺序及源边插入顺序。
- NMI：归一化互信息，使用 scikit-learn 默认的算术平均归一化。
- ARI：调整兰德指数。
- 对八个随机种子报告均值和**总体标准差**（`statistics.pstdev`），按“均值 ± 总体标准差”展示。

保存的参考环境为 Python 3.11.3、python-igraph 1.0.0、leidenalg 0.12.0 和 scikit-learn 1.7.2。复现时使用固定依赖版本及原始公开标识顺序进行构图与评分并列排序。

## 4. RQ2：审阅人候选列表中的非人类占位

### 冻结历史与评价目标

- 历史截止点：**2026-01-01 00:00:00 UTC**。
- 历史 PR 创建时间和审阅事件时间均须严格早于截止点，整个评价块使用截止点前的同一份历史。
- 目标 PR 创建区间：**[2026-01-01, 2026-03-01) UTC**，即 2026 年 1—2 月。
- 每个 PR 的目标集合：在 **[创建时间, 创建时间 + 30 天)** 内实际出现的不同人类审阅人，选取 PR 作者以外的账号。
- 仅评价至少观察到一个上述人类审阅人的 PR。参考结果含 3,012 个仓库的 15,899 个合格 PR；目标区间另有 95,454 个 PR 未观察到这种目标，未进入本次评价。

历史证据和目标均选取 `review`、`review_comment`。每个 `(PR, 审阅人)` 先取最早有效事件，再保留该事件发生于 PR 创建时间及之后的组合。源仓库信息冲突时，以 PR 创建记录中的仓库为准。

### 候选评分与账号范围

对目标 PR，候选人的分数为其在同一仓库审阅过的不同截止点前历史 PR 数。先按分数降序，再按稳定账号键升序排序；候选选取目标 PR 作者以外的账号。

全账号允许类型已知的人类和非人类候选，仅人类只允许人类候选。候选资格依据执行审阅的账号类型确定，人类审阅过非人类作者的历史 PR 仍参与计分。在这个仓库频次评分下，筛选后的人类候选保持原有相对顺序。

方法章节同时给出作者合作评分，终稿 RQ2 使用仓库频次评分。

### 评价与预期结果

计算 `k = 1, 3, 5, 10, 20`：

- **Hit@k**：前 k 名是否包含至少一名实际目标审阅人。
- **Recall@k**：前 k 名包含该 PR 目标审阅人的比例。
- **MRR@10**：排名最高的实际目标审阅人若在前十名内，取其名次倒数，否则为零。

准确性指标均对 15,899 个合格 PR 等权求平均，空候选列表记零。非人类位置占比则用非人类位置总数除以**所有实际返回的前十候选位置数**。

| 指标 | All-known | Human-only |
|---|---:|---:|
| Hit@10 | 0.6097867790427071 | 0.6170828353984528 |
| Recall@10 | 0.5711480805920707 | 0.579449591019501 |
| MRR@10 | 0.4322625112690526 | 0.49252014452341514 |
| 前十位置的非人类占比 | 0.28621163087182505 | 0 |
| Hit@1 | 0.3529152776904208 | 0.4268821938486697 |
| Hit@20 | 0.6319265362601422 | 0.6336247562739795 |

28.62% 对应 **23,348 / 81,576 个实际返回位置**，分母为实际返回的 81,576 个前十候选位置，按位置汇总。

新输出为 `outputs/rq2/reviewer_metrics.csv` 和 `outputs/rq2/summary.json`，保存的参考证据位于 `results/reference/rq2`。

## 5. RQ3：项目协作与维护测量

### 记录条件与分母

从 4,222,224 条保存输入中，选取类型已知、包含执行账号及有效时间的活动记录，并排除合成 PR 工具标签，得到 **2,721,064 条可用于维护统计的活动记录**。

| 记录类别 | 人类 | 非人类 | 总计 |
|---|---:|---:|---:|
| 可用于维护统计的活动 | 1,419,177 | 1,301,887 | 2,721,064 |
| 正式审阅与行级审阅评论 | 264,270 | 306,651 | 570,921 |

非人类活动占维护统计有效记录的 47.84%，分母为 2,721,064；非人类审阅活动占审阅交互记录的 53.71%，分母为 570,921。

分析覆盖 25,402 个仓库、361,296 个 PR、54,065 个仓库—月份行，以及 2024 年 12 月至 2026 年 4 月的 17 个月。

### 五个指标

1. **活跃账号数**：一个仓库的事件月份内不同执行账号的数量。
2. **审阅人数**：该仓库的事件月份内产生 `review` 或 `review_comment` 的不同账号数。
3. **审阅集中度（HHI）**：各账号在正式审阅与行级评论原始记录中所占份额的平方和，按原始事件行逐条累计。
4. **k50**：按审阅记录数降序排列，覆盖至少一半记录所需的最少账号数。
5. **首次正式审阅时间**：PR 创建至所选范围账号最早有效 `review` 的小时数，按 PR 创建月份分组。正式审阅以 `review` 关系为准，使用快照中的全部有效正式审阅，包含作者自审。

账号数、审阅人数为零仍是有效观测。HHI、k50 在存在审阅记录的单元上计算，其余单元记为缺失。响应时间在观察到相应正式审阅的 PR 上计算，其余 PR 记为缺失。

### 聚合方法与预期结果

前四个总体指标，均逐仓库保留两种范围都有效的共同月份，分别求月份平均，再对有效仓库等权求平均。配对差值为全账号减仅人类。点估计使用全部有效观测。

| 总体指标 | 全账号均值 | 仅人类均值 | 配对平均差 |
|---|---:|---:|---:|
| 活跃账号 | 2.180274648889759 | 1.4022276123293815 | +0.7780470365603773 |
| 审阅人 | 0.6051421640474958 | 0.3331478922084629 | +0.27199427183903274 |
| HHI | 0.67302705519254 | 0.8631452959052891 | -0.19011824071274908 |
| k50 | 1.210067980282102 | 1.0534363135943559 | +0.15663166668774622 |

活跃账号、审阅人使用 25,402 个仓库对和 54,065 个月份对；HHI、k50 使用 7,846 个仓库对和 16,083 个共同有效月份对。参考值取自最终 v2 快照。

响应时间分别在各范围观察到响应的 PR 上汇总：

| 响应样本 | PR 数 | 预期全体 PR 中位小时数 |
|---|---:|---:|
| 任意合格账号 | 83,074 | 0.5266666666666666 |
| 人类账号 | 59,694 | 1.353888888888889 |

任意账号响应与人类响应分别在各自已观察到响应的 PR 样本上汇总。为精确复现，历史分位数选择 `sorted(values)[int(round(q * (n - 1)))]`，使用 Python 的取偶舍入；当样本数为偶数时选择一个中央顺序统计量。

新输出为 `outputs/rq3/summary.json` 和 `outputs/rq3/monthly_metrics.csv`，保存的参考证据位于 `results/reference/rq3`。

### 月度图与解释

图7，`fig:governance`，对应 `fig_rq3_monthly_metrics_v3.pdf`。前四面板逐月、逐指标保留两种范围均有效的仓库并等权求均值；最后一面板按 PR 创建月份计算 PR 级响应中位数。总体指标先在仓库内平均，月度指标按当月有效仓库求均值。

预期方向检查：

- 全账号在全部 17 个月中有更多活跃账号和审阅人，且 HHI 更低。
- k50 在 15 个月更高，另两个月相同。
- 全部 16 个有效响应月份中，任意账号响应中位数均短于人类响应中位数。
- 2026 年 4 月的有效响应观测数为零，响应时间保留为缺失值。

各月覆盖的仓库与 PR 会变化，曲线按当前快照逐月汇总。
